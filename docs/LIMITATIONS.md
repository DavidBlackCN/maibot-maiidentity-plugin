# 已知限制

- 通用跨插件特权、双端挑战聊天入口、Planner actor、alias 真实传输、旧模板与原始 prompt 日志固定关闭。
- Host 消息作者只证明路由内账号，不等于实名认证或真人证明。未知路由和不匹配 scope 不推断身份。
- 没有精确会话和消息 ID 时不猜最近发言者；未知 Planner schema 跳过，不改写宿主历史或其他插件内容。
- 身份提示仅控制本插件上下文，原始历史或其他插件仍可能带入误导内容；不承诺模型永不误认。
- 双方可通过官方命令确认公开关系，但关系不授予权限，私密关系不向公开模型上下文投影；不修写外部记忆数据库。
- 本地委托状态和对账不代表远程执行许可；通用受保护公共 API 仍拒绝，有限 Vita 命令只按本地管理名单授权。
- 复杂账号与角色配置推荐编辑原始 TOML；没有聊天角色管理或审计查询入口。
- 迁移只支持首次成对激活。激活后直接改配置会因摘要不匹配拒绝启动，不支持在线跨文件升级；中断时保留现场并从快照另建目标。

使用方法见 [README](../README.md)，接口见 [API](API.md)，迁移见 [MIGRATION](MIGRATION.md)。
