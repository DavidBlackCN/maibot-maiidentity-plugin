# 已知限制

- 跨插件特权、双端挑战聊天入口、Planner actor、alias 真实传输、旧模板与原始 prompt 日志均关闭；请求配置为 true 会校验失败。
- SDK/Host 没有本插件可验证的 H03 actor/caller/context_ref 和跨进程原子消费，所有受保护公共 API 明确拒绝。领域 Actor 只能来自受信适配层，不能从 JSON 构造。
- QQ 消息只证明 Host 归属的账号作者，不等于实名认证或真人证明。仅适配配置的主机器人账号与路由 scope；缺少任一字段或自身身份未知时 unresolved。其他机器人账号列表和系统来源的完整证明未接线，因此不授予真人特权。
- 精确查询使用 stream_id 过滤并与缓存核对；API 明确冲突不能回退缓存。没有会话/精确 ID 不猜最近发言者。alias 领域实现要求完整、受信、版本化历史并拒绝碰撞，真实 Host 没有该证明接口，兼容路径关闭。Host 上游已做别名展开但未携带展开证明的链路不能宣称端到端 alias 安全验收。
- 固定 Host Planner 使用 typed items 且无精确 trigger/extra_prompt，实际跳过。一般规则只在提供已核实 extra_prompt 的适配路径使用；不会擅改 typed items、多模态消息或宿主历史。
- 昵称风险中性化只控制本插件模型块；原始历史或其他插件仍可能带入误导内容。正文、引用、转发和记忆声明不变成关系事实。规则可绕过，未命中标签也始终低信任；不承诺模型永不误认。
- 确认关系与动态社交分开。无可见记录仅指当前可见范围；私密关系不向模型投影。动态社交/记忆端口未联通，不修写外部数据库，也不修复已有污染记忆。
- 委托仅实现本地预留、状态、回执和对账，没有远程执行器或生活调度器。没有外部副作用许可；未知结果必须对账，不能用新键重复预留。
- 配置为固定条目 schema，复杂数组推荐离线编辑；初版自定义继承角色只提供受信领域接口。没有远程角色管理、关系确认或审计查询入口。
- 迁移首版只支持首次成对激活。激活后直接改配置会拒绝启动；不支持自动在线配置/DB 跨文件升级。中断状态需保留并从备份另建目标，不自动猜测恢复。
- 基础 Host 冒烟针对原生独立插件运行时，未启动完整 bot CLI/WebUI，不连接真实平台、不发群消息、不调用付费模型。模型效果、完整守护进程、长期性能和真实生态联合测试均未验收。
